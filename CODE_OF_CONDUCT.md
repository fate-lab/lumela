# Code of Conduct

Lumela follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, assume good intent, and focus on what is best for
the community. Harassment, insults and personal attacks are not tolerated in issues,
pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainers
through [GitHub's report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or by opening a [private security advisory](https://github.com/tw4/lumela/security/advisories/new)
marked "Code of Conduct". Reports are handled confidentially.

Maintainers may remove comments, commits, code or issues that break this code of conduct,
and may temporarily or permanently ban contributors who repeatedly do so.
